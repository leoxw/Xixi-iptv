# xixitv 直播源同步仓库

自动同步 [xixitv.live](https://xixitv.live/) 的直播频道，生成标准 M3U 播放列表，可直接导入电视盒子、IPTV 播放器（如 TiviMate、PotPlayer、VLC、AptvPlayer 等）。

## 播放列表

| 文件 | 内容 |
|---|---|
| `playlist.m3u` | 全部频道：每个频道的主线路，外加每条备用线路各一条目（条目名带 `[线路名]` 后缀） |
| `direct.m3u` | 只有第三方 HLS 直链的频道（卫视 + CGTN），普通播放器可直接播放，**日常优先用这个** |
| `cntv.m3u` | 只有央视频道，地址是站内的 `/cntv/live/*.m3u8`，有限制，见下方说明 |
| `channels.json` | 规范化后的频道数据（名称、分组、台标、主线路、备用线路，地址均为绝对地址） |

## 数据来源与同步方式

- 数据源是站点前端自己用的公开接口：`GET https://xixitv.live/api/config`，无需登录，返回全部频道。
- `update.py` 拉取该接口并重新生成上面 4 个文件，只用 Python 标准库，无第三方依赖：

  ```bash
  python3 update.py
  ```

- 仓库带了 GitHub Actions（`.github/workflows/update.yml`）：每 6 小时自动运行一次同步，频道有变化时自动提交；也可以在 Actions 页面手动触发。推到 GitHub 后即生效，不需要自己的服务器。
- 生成文件不带时间戳，频道没变化时不会产生无意义的提交。

频道概况（以 `channels.json` 为准，会随同步变化）：央视、卫视两个分组，含 CCTV 系列、CGTN、湖南卫视、东方卫视 4K 等。

## 关于央视频道的重要限制

央视频道的主地址形如 `https://xixitv.live/cntv/live/cctv1.m3u8`，它不是普通直链：

- 脱离站点页面直接请求该地址会返回 `forbidden`（站点靠浏览器校验放行，具体规则未公开）。
- 它的分片经过 ChinaDRM 加扰，站点播放时靠一个补丁接口逐片还原，普通播放器即使拿到清单也无法直接解出画面。

所以 `cntv.m3u` 只是如实同步站点的地址清单，供研究和在站点内使用；想在外部播放器里稳定看央视，需要另找可直连的央视源替换这部分。卫视和 CGTN 的直链（`direct.m3u`）不受这个限制。

备用线路（`sources`）是站内代理地址 `https://xixitv.live/s/<长串>`，是否过期无法确认，所以每次同步都会从接口重新获取，不要长期缓存旧地址。
